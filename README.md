# 📊 Sales Analytics Dashboard Using Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing sales data using **Microsoft Excel** to build an interactive Sales Analytics Dashboard. The dashboard helps understand sales performance, profitability, product performance, and sales trends through data visualization.

The project demonstrates how Excel can transform raw sales data into meaningful business insights to support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall sales performance and profitability.
- Identify top-performing products and categories.
- Compare sales performance across regions.
- Track sales trends over time.

## 🔄 Project Workflow

1. **Data Collection:** Import the sales dataset into Excel.
2. **Data Cleaning:** Check missing values, duplicates, and inconsistencies.
3. **Data Preparation:** Organize the dataset and standardize formats.
4. **Data Analysis:** Use Excel formulas and PivotTables to summarize the data.
5. **Dashboard Creation:** Build charts, KPI summaries, and interactive filters.
6. **Insight Generation:** Interpret the results to understand business performance.
